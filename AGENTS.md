# MARCELLO.INFRA — Codex Project Instructions

## Projeto

Site comercial B2B para prestação de serviços de infraestrutura, redes, segurança, monitoramento, cloud e automação.

## Objetivo

Gerar leads qualificados e apresentar Marcello como prestador técnico de infraestrutura de TI.

O site não deve parecer um currículo ou página de procura de emprego.

## Princípios

- Priorizar simplicidade.
- Não adicionar dependências sem necessidade.
- Não inventar informações.
- Não inventar clientes, certificações, cases ou experiência.
- Manter linguagem comercial B2B.
- Manter honestidade técnica sobre nível de conhecimento.
- Priorizar performance.
- Priorizar mobile.
- Manter HTML semântico.
- Manter acessibilidade.
- Manter código simples e legível.

## Stack

- Astro
- TypeScript quando necessário
- Tailwind CSS
- Git
- GitHub
- Cloudflare Pages

## Design

Visual:

- B2B
- técnico
- premium
- sóbrio
- moderno
- confiável

Evitar:

- cyberpunk
- gamer
- neon excessivo
- gradientes excessivos
- stock photos clichês
- estética de agência de marketing

## Conteúdo

Posicionamento:

"Infraestrutura que funciona."

Serviços principais:

- Infraestrutura
- Redes
- Segurança
- Monitoramento
- Automação
- Cloud

## Honestidade

Experiência consolidada deve ser apresentada separadamente de tecnologias em aprofundamento.

Nunca transformar estudo ou laboratório em experiência de produção.

Nunca criar números ou resultados sem fonte.

## Alterações

Antes de alterar arquitetura ou adicionar dependências importantes, avaliar se a solução pode ser feita com a stack existente.

Evitar overengineering.

## Qualidade

Antes de concluir uma tarefa:

- executar build
- corrigir erros
- verificar links
- verificar responsividade
- verificar acessibilidade básica
- verificar SEO
- verificar ausência de placeholders visíveis
- verificar ausência de informações inventadas

## Comunicação

Ao finalizar uma tarefa, informar:

1. O que foi alterado.
2. O que foi testado.
3. Resultado dos testes.
4. Pendências reais.
5. Próximos passos recomendados.

Não apenas explicar como fazer: implementar.
